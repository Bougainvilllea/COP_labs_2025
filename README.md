вопросы:
Вспомнить и объяснить, как работают: 
a) Приведения типов reinterpret_cast, static_cast
static_cast - Позволяет преобразовывать один тип в другой, если компилятор видит между ними логическую связь.
(например: double → int (отбрасывает дробную часть))
reinterpret_cast - Грубо говорит компилятору: "Рассматривай этот кусок памяти как другой тип, не задавая вопросов".
(например: Преобразование указателя в число (для сохранения адреса в int))

б) Спецификаторы типа extern, const
extern - Говорит компилятору: "Не создавай новую переменную, а используй ту, что определена где-то ещё".
(например: В file1.cpp есть int x = 5; В file2.cpp пишешь extern int x; → теперь можно использовать x из file1.cpp.)
const - Делает переменную или метод неизменяемыми.
(например: const int x = 10; → x теперь всегда 10, изменить нельзя. const MyClass obj; → у obj можно вызывать только const-методы (которые не меняют поля))

с) Ссылки
- Даёт другое имя уже существующей переменной.
(например: int a = 5; int& ref = a; → теперь ref это просто второе имя для a. Если изменить ref, то изменится и a.)
(Отличие от указателей: Ссылка не может быть null (всегда ссылается на что-то). Часто используются в функциях для передачи параметров без копирования.)
